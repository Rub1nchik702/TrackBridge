TrackBridge 1.14.0 · Windows 10/11 · Rub1nchik

TrackBridge adds Twitch Channel Points song requests to your Spotify queue.
Download TrackBridge.exe from GitHub Releases and run it from a writable folder.
To update, close TrackBridge and replace TrackBridge.exe in the same folder.
Keep the data folder to retain your connections and history.

Open Overview → Setup wizard to connect Twitch and Spotify, select a reward,
and check the player. Start reception from Overview when ready.
Open Demo mode to practice with test orders before connecting your accounts.
