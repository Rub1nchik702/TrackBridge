TrackBridge 1.13.1 · Windows 10/11 · Rub1nchik

Заказы музыки за баллы канала Twitch попадают в очередь Spotify.
Для работы нужны Spotify Premium и доступ к пользовательским наградам Twitch.

Скачайте архив TrackBridge-1.13.1-win.zip со страницы выпуска, распакуйте
его и запустите TrackBridge.exe. При обновлении закройте приложение
и сохраните папку data рядом с EXE. В ней хранятся история и подключения.

В настройках укажите Client ID своих приложений Twitch и Spotify,
подключите аккаунты, выберите награду и включите воспроизведение Spotify.
В обзоре нажмите «Запустить».

Таймер выбора трека по умолчанию составляет 15 минут. Значение 0 выключает
автовозврат. Если Spotify мог уже принять трек, заказ ждёт ручного решения.
Если Twitch подтвердил возврат, ошибка сообщения в чат сохраняет результат.
Исправление проверено на истории из 500 завершённых заказов.

Исходники Rust находятся в rust/. Условия использования описаны в LICENSE.txt.
