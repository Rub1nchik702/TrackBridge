# Version policy

Feature releases increment the minor version, for example 1.9.0 to 1.10.0. Interface and design fixes use a fourth numeric component, for example 1.9.0.1. These four-component versions are supported by the updater starting with 1.9.0. Users of earlier versions should first upgrade to 1.9.0.

Versions before 2.0.0 may carry a -beta.N suffix. Starting with 2.0.0, official releases must have no beta suffix and must not be labelled as GitHub pre-releases. The main README is English; Russian is README.ru.md.
