# Version policy

Feature releases increment the minor version, for example 1.9.0 to 1.10.0. Functional fixes increment the patch version, for example 1.11.0 to 1.11.1. Major compatibility changes increment the major version. Interface and design fixes use a fourth numeric component, for example 1.9.0.1. These four-component versions are supported by the updater starting with 1.9.0. Users of earlier versions should first upgrade to 1.9.0.

As requested by the author, official stable releases starting with 1.9.0.1 have no beta suffix and are published as regular GitHub releases with the Latest label. GitHub releases require a version tag; that tag is retained for downloads and automatic updates. The main README is English; Russian is README.ru.md.
